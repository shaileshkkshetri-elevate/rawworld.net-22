# RAW – Revolutionary Agriculture War

**World's First Agriculture Game Reality Show**  
Official web application for RAW (`rawworld.net`), produced by E Square Private Limited (Copyright Certificate No. 1531).

## Highlights & Features

- **The Show**: Explores the Agritainment genre, bringing together professional farmers and agricultural graduate scientists.
- **One Tree, One Vote**: 289,973 verified living trees planted as democratic audience votes, featuring an interactive climate impact simulation.
- **Real-World Impact**: 103+ schools reached, 200+ policymakers engaged, and international expansion to Bihar, India.
- **Season One Champions**: Trophies and recognition for Farmer Champion Laxman K.C., Graduate Champion Samriddha Bhantana, and Climate Award winner Suman Bimali.
- **Interactive Production Gallery**: High-resolution on-set photography with a full lightbox viewer and keyboard navigation.
- **Leadership & Vision**: Profiles of Maha-Host Rajesh Hamal, Chief Judge Dr. Yogendra Kumar Karki, and Creator/Director Shailesh Kandel Kshetri.
- **Investor & Partner Inquiries**: Interactive deck request flow with pre-formatted dispatch to `hello@rawworld.net`.

## Tech Stack

- **Framework**: React 19 + TypeScript
- **Styling**: Tailwind CSS + Custom Dark/Gold luxury theme
- **Build Tool**: Vite
- **Icons**: Lucide React
- **Port**: 3000

## Development

```bash
npm install
npm run dev
```

To build for production:
